# 跨境电商 FBA 专线物流系统

面向跨境电商与 FBA 头程业务的物流管理系统，包含客户端与后台管理端。支持运单、渠道、客户、货箱申报、费用账单及本地业务数据管理。

## 功能

| 模块 | 支持内容 |
| --- | --- |
| 客户端 | 运单创建与修改、状态筛选、货箱与申报信息、Excel 单票及多票导入、导出与详情 |
| 渠道管理 | 渠道新增、修改、停用、归档，承运商、目的国家、运输方式及本地费率维护与试算 |
| 客户管理 | 客户资料、客户编码、结算方式、信用额度与可用渠道维护 |
| 运单操作 | 客户与渠道分配、货箱实测、承运商单号、状态流转、问题件与路由登记 |
| 财务管理 | 实测锁价开账、已核实收款、关联核销、核销撤销、退款、账单冲销及按币种子账 |
| 商业审批 | 费率生效、锁单实测更正、账单调整及退款审批，申请人与审核人分离 |
| 资料维护 | 地址库、产品库、VAT、店铺资料，预约取件及舱位申请的本地记录 |
| 管理工具 | 批量状态更新、批量取消、本页导出、操作日志 |

客户端与管理端使用一致的顶部菜单、状态页签、表格和右侧表单抽屉，共用 SQLite 本地数据库。系统不预置真实订单或客户资料。

## 架构与安全

后端工程位于 [`backend/`](backend/README.md)，不是只有前端页面。采用Node.js模块化单体，分离HTTP路由、身份认证、角色权限、业务服务、客户范围仓储、事务和数据库迁移。

0.8默认要求登录，区分管理员、运营、财务和客户；客户账号绑定客户数据范围，管理接口不能由客户端账号调用。会话使用HttpOnly Cookie，写接口校验CSRF和来源，退出/停用/权限修改撤销会话，密码使用独立盐的scrypt哈希，不设默认账号密码。

生产环境员工强制启用验证器双重验证。运单和账单关联增加关系表及数据库约束；预付、信用额度与逾期检查控制放货。

客户修改账单会提交审核申请，只有有权限的财务人员通过审核后才更新应收明细；核销历史和原账单版本保留。Excel解析已升级并放入限时Worker，接口、文件和ZIP目录都有大小限制。

整改与待验收事项见[0.8 交付说明](docs/RELEASE-0.8.md)，默认业务政策见[业务规则](docs/COMMERCIAL-RULES.md)。

完整边界见[架构说明](docs/ARCHITECTURE.md)与[安全说明](SECURITY.md)。这些修复不等于已经通过独立渗透测试或完成生产部署。

## 快速启动

需要 Node.js 24 或更新版本，已在 Node.js 26.12.0 验证。无需安装 npm 依赖。

```bash
# 首次运行先创建管理员，交互输入两次密码（至少15位、不回显）
npm run user:create -- --username your-admin --role admin
npm run dev
```

- 客户端：http://127.0.0.1:4188/tms/wos/shipment
- 后台管理端：http://127.0.0.1:4188/admin

首次启动会自动创建 `data/logistics.sqlite`。数据库与本地配置不上传代码仓库。

## 验证

```bash
npm test
npm run test:capacity
```

测试包括业务回归与独立安全测试，覆盖渠道与客户维护、账单修改与核销、批量事务回滚、版本校验、Excel 解析、HTTP 接口及重启持久化。测试使用独立临时数据库和操作系统分配的本机临时端口。

## 部署说明

默认仅监听 `127.0.0.1`。生产模式强制HTTPS域名及受信反向代理配置；账号、角色与客户范围隔离已加入，已提供加密备份、恢复校验、定时任务及监控模板。生产主机压测、独立渗透测试、真实异地恢复和告警接收仍需验收；承运商、银行支付、财税和多实例高可用尚未接入。默认费率模型及财务子账范围应先按实际合同确认。详见[初始化与部署](docs/DEPLOYMENT.md)。
