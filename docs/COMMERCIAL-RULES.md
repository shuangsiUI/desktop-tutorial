# 0.8 业务规则与会计边界

这是当前实现的默认规则，供物流、财务负责人逐项验收；不是已经获得业务负责人签字的制度。日期按 UTC 日历日处理，手工账单可填写实际账单及到期日期。币种独立核算，不自动换汇。

## 运单与客户

- 客户身份由账号绑定，已有归属的运单、账单和资料禁止直接转给其他客户。客户、运单、账单及其关联增加关系表、外键和数据库约束；动态表单字段继续保存在 JSON 文档中。
- 未分配的旧数据继续只对员工可见。有关联的旧运单和账单必须一致；升级遇到已有错误归属时回滚商业迁移，保留原始数据和升级前快照，不能自动猜测归属。
- 运单状态为已下单 → 已收货 → 转运中 → 已签收；另支持允许节点上的取消、退件。已有有效账单时不能直接取消。必须先撤销核销、处理客户余款并经审批作废账单；客户余款可以退还或继续保留为预付款。
- 已开账单、出库、签收的计费数据锁定。实测更正由运营申请、另一名管理员复核；重新计算仍使用原费率快照。若修改后账单低于已核销额，审批失败并整体回滚，须先处理原核销。

## 渠道、计费与放货

- 新渠道先停用，财务或有权限员工提交费率申请，另一名管理员复核后启用。调整费率同样审批，已生成的账单不随新费率改变。
- 实重和体积重取大，与最低计费重比较后按重量阶梯进位，整票固定费只收一次；同箱多个 SKU 只计一次箱重。十进制有理数运算避免浮点进位多收费用，金额以整数分保存。
- 当前合同模型支持每公斤费率、最低重量、材积系数、重量进位和整票固定费；暂未实现分区阶梯价、燃油指数、旺季价、偏远区及税费自动规则。不能将此模型用于不符合这些条件的渠道而不做定制。
- 锁价开账要求客户、渠道、国家、服务、可用渠道和币种匹配，全部货箱已实测。保存运单版本和完整费率快照，防止同一票重复自动开账；已有手工账单会拦截自动开账，要求先核对。
- 出库必须完成客户及渠道分配、实测、锁价开账和承运商单号录入。
- 预付客户必须付清本票账单；周结/月结客户必须无逾期，且应收不超过信用额度。存在其他币种欠款时先结清，不能把不同币种金额直接相加比较额度。
- 自动周结到期日为开账后 7 天；月结为下一个月同日、月底夹紧（1 月 31 日对应 2 月末）。需要自然月结、固定账期日等其他规则时应先调整策略并验收。
- 放行时保存信用检查时间、客户版本和账单版本；之后发生核销撤销会重新形成应收，不追改已经发生的物流事实。

## 财务凭证

| 操作 | 借方 | 贷方 | 约束 |
| --- | --- | --- | --- |
| 开账/增加应收 | 应收 | 业务收入 | 同客户同币种，有原因及版本 |
| 减少应收/冲销 | 业务收入 | 应收 | 不得低于已核销额，保留历史 |
| 已核实收款 | 银行 | 客户预收 | 银行账户标识、实际流水号唯一 |
| 收款核销 | 客户预收 | 应收 | 关联原收款，同客户同币种，不超可用额 |
| 撤销核销 | 应收 | 客户预收 | 追加反向凭证，一次核销只能撤销一次 |
| 退款 | 客户预收 | 银行 | 关联原收款，不超余款，另一名管理员复核 |
| 历史期初未收 | 应收 | 期初余额 | 只建立迁移时未收额，不虚构现金到账 |

每张凭证必须借贷平衡才能过账；已过账凭证和分录禁止修改、删除。收款参考号幂等，同一银行流水不能换一个参考号再次登记。退款审批时再次检查原收款及总余额，竞争审批不能透支。

账单保存 issued/void 生命周期，并以余额显示未核销、部分核销或已核销。手工账单由财务保留原因直接修订；系统计费账单须提交调整审批。客户修改是申请，审核前原账单金额不变。已作废账单不能编辑、核销或用于放货。

这是物流应收和预收的业务子账，不是完整法定总账、报税或银行支付系统。银行到账与退款付款由财务核实，登记不触发转账；税务发票、应付承运商、总账科目、汇兑损益等需在外部财务系统处理或另行开发对接。任何显示的“收款”都要求有实际凭据，不能用测试数据代替。

## 职责与审计

- 运营处理运单、实测及资料，可以提出费率/实测申请，不能直接改费率或核销资金。
- 财务处理收款、账单、核销及申请。管理员审核商业申请，申请人与审核人必须不同；至少准备两名不同员工账号。
- 员工生产登录必须使用密码和验证器验证码。密钥加密存储，验证码防重放；服务器运维核验身份后才能重置。
- 变更审计记录操作者、目标客户、请求号及业务摘要前后值；财务历史另保留原费用明细与原因。审计摘要不复制密码或完整地址/联系方式。数据库管理员仍具有底层控制权，需结合主机权限及异地留存保护。

## 日常验收流程

建客户 → 建渠道 → 另一人审核费率 → 客户下单 → 运营分配、实测、收货 → 财务锁价开账 → 核实收款并核销或通过账期信用检查 → 出库 → 路由及签收。

取消流程：停止物流处理 → 核对费用 → 如有核销则撤销 → 核对退款或保留预付款 → 另一人审核账单作废 → 取消运单。已在途/签收账单不允许整单作废，使用有原因的费用更正处理。
